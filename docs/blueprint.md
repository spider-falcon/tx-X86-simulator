# **App Name**: X86 Simulator

## Core Features:

- Code Editor: Provides a code editor with syntax highlighting and breakpoint support for writing assembly code.
- Assembly Parsing: Parses assembly code into machine-executable instructions.
- Instruction Execution: Executes parsed instructions within a simulated x86 environment.
- Register and Flag Display: Displays CPU register values and flag statuses during execution.
- Memory and Stack Viewer: Visualizes memory and stack contents to track program behavior.
- Execution Controls: Provides controls such as Step, Run, and Reset to manage program execution.
- I/O Console Output: Simulates input and output operations to provide program feedback.

## Style Guidelines:

- Primary color: Deep orange (#FF851B), evoking computation with a retro feel.
- Background color: Very light desaturated orange (#F5E9DE), offering a gentle contrast.
- Accent color: Light red (#FF4136), drawing the eye to controls.
- Body and headline font: 'Inter', a sans-serif offering a modern and machined aesthetic.
- Code font: 'Source Code Pro' for clear and legible code display.
- Use minimalist icons to represent simulator controls and status indicators.
- Incorporate subtle animations for instruction highlighting during execution.
